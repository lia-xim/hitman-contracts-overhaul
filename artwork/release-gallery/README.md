# HCO release gallery

Five 1672 x 941 landscape images for the Steam Workshop gallery and release posts.

## Recommended order

1. `01-release-key-art.png` - main release image and announcement cover.
2. `02-drone-response-network.png` - the seven-model Scout/Light/Heavy roster.
3. `03-contract-gameplay-loop.png` - field intelligence, target tracking, approach choice, and payout.
4. `04-security-escalation.png` - patrol, confirmed contact, hunt, and destructible counterplay.
5. `05-disguise-social-stealth.png` - disguise acquisition, plausible behavior, suspicion, and compromise.

## Generation notes

The images were generated with the built-in OpenAI image tool from HCO's own
drone concept sheets, wreck sheet, existing Workshop header, and real gameplay
screenshots. The prompts deliberately avoid fixed balance statistics and systems
that are not present in the current release candidate.

The contract-loop image is the corrected second pass. It contains no invented
fixed payout and uses `FIELD INTELLIGENCE / TARGET LOCATION REVEALED` for the
opening step.

## Core prompt set

- Release key art: a protected target, five close guards, an infiltrator, a
  Scout search cone, a light armed drone, and a charging Heavy Laser drone in a
  nocturnal industrial compound.
- Drone roster: exactly seven top-down models arranged as Scout, three Light,
  and three Heavy variants with Pistol, SMG, and Laser labels.
- Contract loop: four connected stages - recover intel, track the moving target,
  infiltrate or attack, and claim the campaign reward while the mission continues.
- Security escalation: routine patrol, confirmed contact, response convergence,
  armed standoff, and a drone being shot into its persistent wreck state.
- Social stealth: take a disguise, blend in with plausible behavior and a
  keycard, raise suspicion through overt behavior, and compromise the identity
  when its source body is discovered.

All generated text was constrained to the visible headings and labels in the
final images. No game or third-party logo is embedded in the artwork.
