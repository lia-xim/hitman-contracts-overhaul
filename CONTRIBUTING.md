# Contributing

HCO is specification-driven and native-first. Focused bug fixes, map profiles, tests, translations, and systemic features are welcome.

1. Read `docs/SPECIFICATION.md` before changing game behavior.
2. Prefer stable native systems and graceful no-op behavior over a custom overlay or broad monkey patch.
3. Preserve vanilla objectives, named/scripted actors, unknown maps, and old saves when safety cannot be proven.
4. Keep automated fixture proof separate from observed in-game proof.
5. Do not commit game files, decompiled source, extracted game assets, saves, personal paths, or crash logs with private information.
6. Include a focused test and update the changelog for player-visible changes.

By contributing, you agree that code is licensed under MIT and original media contributions under CC0 unless clearly documented otherwise.
