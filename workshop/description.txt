[h2]NATIVE-FIRST DESIGN[/h2]
There is no cheat menu, F-key overlay, separate currency or external progression screen. HCO uses native objectives, moving markers, actors, patrol routes, radios, credentials, projectiles, damage, security-camera carriers, world quadtrees and campaign saves.

Unsafe missions and story-critical actors are skipped instead of being forced into a contract. Drone attacks require confirmed tracking, line of sight, range, gimbal alignment, a visible cue and a cooldown. Every model remains shootable or electronically disruptable.

[h2]HOW TO START[/h2]
Start a compatible mission from the beginning. No hotkey is required. Follow the optional intelligence objective, recover the marked dead drop and infiltrate or fight through the target's protection.

[h2]COMPATIBILITY[/h2]
Built for Intravenous 2 [b]1.4.12HF3[/b]. Install only one HCO copy. If both a local and Workshop copy are enabled, the first-loaded version wins.

The Intravenous 2 Cheat Trainer is supported. For a meaningful combat test, use [b]Reset all cheats[/b] first; God Mode still prevents drone damage.
